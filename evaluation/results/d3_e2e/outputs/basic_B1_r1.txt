## 三、ANCE

**资料中有依据的结论：**

1. **预训练语言模型**：片段4指出 "ANCE (Xiong et al., 2020) uses RoBERTa_base"。
2. **负样本策略（BM25 预热）**：片段1明确说明 "ANCE is also warmed up by BM25 negatives"，即在 TREC DL 实验中，ANCE 先用 MARCO 官方 BM25 负样本进行预热训练。
3. **OpenQA 场景的初始化**：片段1指出 "In OpenQA, we warm up ANCE using the released DPR checkpoints (Karpukhin et al., 2020)"，即 ANCE 在 OpenQA 任务中使用 DPR 发布的 checkpoint 进行预热。
4. **ANCE 的核心机制（间接）**：ANCE 以"近似最近邻负样本"著称（名称即 Approximate Nearest Neighbor Negative Contrastive Estimation），但**片段中并未直接描述其负样本刷新机制**，仅提到 BM25 预热。

**资料中未找到的信息：**

- ANCE 的负样本刷新频率、候选池大小等细节

**推测（明确标注为推测）：** 结合片段1"BM25 Warm Up"的描述，ANCE 的训练流程可能是"BM25 负样本预热 → 自身检索器挖掘的近似负样本"，但片段未直接证实后半部分。

## 四、RocketQA

**资料中有依据的结论（片段2、3、5 信息最丰富）：**

1. **三大核心训练策略**（片段2、3、5一致）：
   - **Cross-batch negatives（跨批次负样本）**：相比 in-batch negatives，增加每个问题可用的负样本数量，并缓解训练与推理之间的差异。
   - **Denoised hard negatives（去噪硬负样本）**：从检索器 top-ranked 结果中移除假负样本（false negatives），得到更可靠的硬负样本。
   - **Data augmentation（数据增强）**：利用 cross-encoder 对大规模无监督数据生成高质量伪标签，用于训练 dual-encoder 检索器。

2. **蒸馏/数据增强的具体机制**（片段2）：RocketQA 使用 cross-encoder 为无标签数据生成高质量伪标签（pseudo labels），再用于训练 dual-encoder。这本质上是一种**跨架构蒸馏 + 数据增强**的结合。片段2还指出 cross-encoder 在理论和实践上都比 dual-encoder 更强（引用 Luan et al., 2020），但效率低，因此用作"教师"。

3. **预训练语言模型**（片段4）：RocketQA 主要使用 **ERNIE_base**；作为对比实验，也用 BERT_base 替换 ERNIE_base，性能略降（MSMARCO MRR@10 降约 0.6，NQ R@100 降约 1.6）。片段4还指出，仅用 cross-batch negatives 训练的 RocketQA 已可与 DPR、ANCE、ME-BERT 相比（尽管后者用了更好的预训练 LM）。

4. **训练数据（间接）**：片段1提到 TREC DL 实验中包含 "BM25 Warm Up" 设置，所有 DR 模型从 RoBERTa base 微调，并使用 MARCO 官方 BM25 负样本。但这是该实验的设置，**RocketQA 原始论文的训练数据细节（如是否用 MARCO、NQ 等）在片段中未完整给出**。

**资料中未找到的信息：**
- RocketQA 的具体训练数据集规模与来源
- Cross-batch negatives 的具体 batch 大小、跨批次数量
- Denoised hard negatives 的去噪阈值/过滤规则
- Cross-encoder 教师模型的具体架构与训练细节

## 六、结论与资料缺口

**有依据的核心结论：**
- RocketQA 的三大策略（cross-batch negatives、denoised hard negatives、cross-encoder 伪标签数据增强）在片段中有明确、反复的陈述。
- ANCE 使用 BM25 负样本预热，OpenQA 场景用 DPR checkpoint 初始化。
- DPR 用 BERT_base，ANCE 用 RoBERTa_base，RocketQA 主要用 ERNIE_base。

1. **ColBERT 完全缺失**，无法做任何有依据的对比。
