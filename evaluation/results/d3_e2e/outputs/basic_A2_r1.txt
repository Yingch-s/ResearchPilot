## 一、RocketQA（资料依据较充分）

### 1. 训练数据
根据片段1和片段2，RocketQA 的训练数据来源包括：

- **有标注的训练数据**：用于训练 dual-encoder 的问答对（具体数据集名称在片段中未明确列出，但实验在 MSMARCO 和 Natural Questions 上进行，见片段2）。
- **大规模无监督数据**：片段1明确指出 "RocketQA leverages large-scale unsupervised data 'labeled' by a cross-encoder for data augmentation"。即利用 cross-encoder 为无标注数据生成高质量的**伪标签（pseudo labels）**，再用于训练 dual-encoder。
- **hard negatives**：通过 retriever 检索 top-ranked 结果，再用去噪（denoised）方式得到可靠的 hard negatives（片段1）。
- **cross-batch negatives**：在训练中引入跨 batch 的负样本（片段1）。

### 2. 标注需求
RocketQA 的标注需求特点：

- **减少对人工标注的依赖**：核心贡献之一就是用 cross-encoder 对无监督数据自动生成伪标签，从而做数据增强（片段1、片段2）。这意味着它**不需要对全部训练数据做人工标注**。
- **需要去噪处理**：由于检索出的 top-ranked 结果可能包含 false negatives，RocketQA 引入 "denoised hard negatives" 来去除假负例，说明其对负样本质量有额外处理需求（片段1）。
- **预训练语言模型**：主要使用 ERNIEbase，也测试过 BERTbase（片段4）。

## 二、ANCE（资料有部分依据）

### 1. 训练数据
根据片段3：

- ANCE 在 TREC DL 上使用 **MARCO passage 训练数据**，并采用 **BM25 Warm Up** 设置，即先用 MARCO 官方的 BM25 negatives 训练（片段3："the DR models are first trained using MARCO official BM25 Negatives. ANCE is also warmed up by BM25 negatives"）。
- 在 OpenQA 任务上，ANCE 使用 **DPR 发布的 checkpoint** 进行 warm up（片段3："we warm up ANCE using the released DPR checkpoints"）。
- ANCE 使用 **RoBERTabase** 作为预训练语言模型（片段4）。

### 2. 标注需求
- 片段3提到 MARCO passage 训练标签被研究发现"cleaner"（Yan et al., 2019），说明 ANCE 依赖 MARCO 的标注数据。
- ANCE 的核心思想是使用**动态/周期性更新的 hard negatives**（从模型自身检索结果中挖掘），但这一细节在提供的片段中**未直接出现**，属于该论文的常识性背景，此处不作展开以免超出资料依据。
- 资料未明确说明 ANCE 是否需要额外的人工标注。

提供的片段中**没有直接说明 DPR 使用了什么训练数据**。仅有以下间接信息：
