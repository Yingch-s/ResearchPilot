# A1 · b0 · round 1

DPR、ColBERT、ANCE、RocketQA 四篇论文各自提出的检索/建模核心方法是什么？

---

这四篇工作都是稠密检索/神经检索方向的重要论文，核心方法可以概括如下：

1. **DPR（Dense Passage Retrieval，2020）**
   - 核心方法：用**双塔（dual-encoder）稠密检索**替代传统的稀疏检索（如 BM25）。
   - 具体做法：分别用两个 BERT 编码器把问题和段落映射到同一个低维向量空间，检索时用**最大内积搜索（MIPS）/向量相似度**找最相关段落。
   - 训练：用**对比学习**，以问题为正样本段落、batch 内其他段落为负样本进行训练；推理时对全库段落向量建索引做近邻搜索。
   - 关键点：证明了“问题编码器 + 段落编码器”的稠密向量检索在开放域 QA 上可以显著优于 BM25。

2. **ColBERT（2020）**
   - 核心方法：**延迟交互（late interaction）** 的多向量检索模型。
   - 具体做法：不把整个问题/段落压成单个向量，而是保留 token 级向量；用 BERT 分别编码 query 和 document 的每个 token，然后通过 **MaxSim** 操作计算细粒度相似度：
     - 对每个 query token，找 document 中与其最相似的 token 向量；
     - 再对这些最大相似度求和，作为 query-document 得分。
   - 特点：兼顾了双塔检索的效率和交叉编码器的细粒度匹配能力；通常配合倒排/向量索引加速。

3. **ANCE（Approximate Nearest Neighbor Negative Contrastive Learning，2021）**
   - 核心方法：针对稠密检索训练中的**负采样问题**，提出用**近似最近邻（ANN）检索出的负样本**来训练双塔模型。
   - 具体做法：不是只用 batch 内负样本或随机负样本，而是周期性地用当前模型对全库做 ANN 检索，把检索到的高分但非正例的段落作为“难负样本”加入训练。
   - 关键点：让负样本分布更接近推理时真实候选分布，从而缓解训练/推理不一致，提升稠密检索效果。

4. **RocketQA（2021）**
   - 核心方法：面向稠密段落检索的一套**训练优化方案**，主要解决负样本、数据增强和跨批次问题。
   - 常见要点包括：
     - **跨批次负样本（cross-batch negatives）**：在多 GPU 训练时，把其他 GPU 上的正样本也作为当前样本的负样本，扩大负样本数量；
     - **去噪难负样本（denoised hard negatives）**：对难负样本进行过滤/去噪，减少假阴性；
     - **数据增强**：如用教师模型或回译等方式增强训练数据。
   - 目标：在双塔稠密检索框架下，通过更有效的训练策略提升检索性能，尤其在 MS MARCO 等基准上表现突出。

补充说明：  
- DPR、ColBERT、ANCE、RocketQA 都属于“稠密检索/神经检索”路线，但侧重点不同：DPR 偏基础双塔范式，ColBERT 偏多向量延迟交互，ANCE 偏负采样，RocketQA 偏训练策略与数据优化。
