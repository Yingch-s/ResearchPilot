下面按“从 DPR 到 RocketQA”的时间与问题意识演进，梳理四篇论文中负样本策略的主线。这里说的四篇论文是：

1. **DPR**：Karpukhin et al., 2020, *Dense Passage Retrieval for Open-Domain Question Answering*
2. **ANCE**：Xiong et al., 2021, *Approximate Nearest Neighbor Negative Contrastive Learning for Dense Text Retrieval*
3. **RocketQA v1 / RocketQA 初版**：Qu et al., 2021, *RocketQA: An Optimized Training Approach to Dense Passage Retrieval for Open-Domain Question Answering*
4. **RocketQA v2 / RocketQAv2**：Ren et al., 2021, *RocketQAv2: A Joint Training Method for Dense Passage Retrieval and Passage Re-ranking*

需要先说明：如果你说的“四篇论文”不是这四篇，而是把 RocketQA 系列拆成不同版本，或把 ColBERT、Sentence-BERT 等也算进去，那么主线会略有不同。下面按 DPR → ANCE → RocketQA → RocketQAv2 这条最自然的演进线来讲。

---

## 一、总体主线

从 DPR 到 RocketQA 系列，负样本策略的核心演进可以概括为：

> **从“静态、随机/BM25 负样本”走向“动态、模型相关、难负样本”，再走向“去噪、跨模型监督、联合训练中的负样本与蒸馏协同”。**

更具体地说：

1. **DPR**：负样本主要来自 BM25 或随机采样，训练前固定，属于静态负样本。它解决了“用稠密向量做检索”的可行性问题，但负样本质量有限。
2. **ANCE**：提出用近似最近邻检索动态更新负样本，让负样本随着模型训练不断刷新，属于动态难负样本。它解决了静态负样本很快不再“难”的问题，但计算开销大，且可能引入假阴性。
3. **RocketQA**：在 ANCE 基础上进一步系统化负样本策略，强调跨批次负样本、去噪、数据增强和更有效的难负样本采样。它把负样本策略从“动态难负样本”推进到“高质量、可扩展、带去噪的训练流程”。
4. **RocketQAv2**：把检索器和重排器联合训练，负样本不再只服务于双塔检索器，而是与重排器、蒸馏、动态难负样本结合。它代表负样本策略从“单模型训练技巧”上升为“检索-重排联合优化中的核心机制”。

---

## 二、DPR：静态负样本，奠定双塔检索训练范式

### 1. 背景
DPR 的目标是用双塔稠密检索器替代传统 BM25 稀疏检索。它把问题和段落分别编码成向量，用内积或余弦相似度检索。

### 2. 负样本策略
DPR 训练时，每个问题通常配一个正样本段落，再配若干负样本段落。负样本来源主要有：

- **随机负样本**：从语料中随机抽取段落。
- **BM25 负样本**：用 BM25 检索出与问题词面匹配但未必真正相关的段落。
- **同一批次内其他问题的正样本**：即 in-batch negatives。

DPR 论文中比较重要的一点是：  
它发现 **BM25 负样本 + in-batch negatives** 的组合通常效果较好。也就是说，负样本不必全部是随机段落，词面相似但语义不相关的段落更有训练价值。

### 3. 局限
DPR 的负样本在训练前基本固定，或者只依赖外部 BM25。随着模型变强，这些负样本会逐渐变得“太容易”，无法继续提供有效梯度。此外，in-batch negatives 受 batch size 限制，且可能把同一问题的其他正样本误当负样本。

### 4. 在主线中的位置
DPR 是起点：  
它证明了稠密检索可行，并确立了“正样本 + 负样本 + in-batch negatives”的基本训练框架。但负样本策略仍是静态的、外部的、非自适应的。

---

## 三、ANCE：动态近似最近邻负样本，让负样本随模型进化

### 1. 背景
ANCE 针对 DPR 的一个关键问题：静态负样本很快不再难。模型训练到一定程度后，固定的 BM25 或随机负样本已经很容易被区分，训练收益下降。

### 2. 负样本策略
ANCE 的核心是 **Approximate Nearest Neighbor Negative Contrastive Learning**：

- 用当前模型对全语料做近似最近邻检索。
- 对每个问题，取检索得分较高、但不是正样本的段落作为负样本。
- 这些负样本会随着模型参数更新而重新检索、重新选择。
- 因此负样本是 **动态的、模型相关的、全局语料级别的难负样本**。

这和 DPR 的静态负样本形成鲜明对比：  
DPR 的负样本来自训练前固定的 BM25 或随机采样；ANCE 的负样本来自当前模型自己认为“像正样本”的段落。

### 3. 贡献
ANCE 证明：  
动态难负样本可以显著提升稠密检索效果，尤其是在大规模语料上。它把负样本从“外部静态信号”变成“模型自身判别边界的挑战者”。

### 4. 局限与风险
- **计算开销大**：需要频繁做 ANN 检索和刷新负样本。
- **假阴性问题**：ANN 检索出的高分段落不一定真的不相关，可能只是标注未覆盖。把它们当负样本会伤害训练。
- **训练不稳定**：难负样本太强时，模型可能难以收敛。

### 5. 在主线中的位置
ANCE 是负样本策略演进的关键转折：  
从 DPR 的静态负样本，转向动态难负样本。但它还没有系统解决假阴性和训练效率问题，这为 RocketQA 的改进留下空间。

## 四、RocketQA：系统化负样本去噪、跨批次与数据增强

### 1. 背景
RocketQA 初版的目标是进一步优化稠密段落检索训练。它认为 DPR/ANCE 之后，主要瓶颈不只是“负样本够不够难”，还包括：

- 负样本中可能有假阴性；
- batch 内负样本受 batch size 限制；
- 训练数据规模和质量不足；
- 单塔/双塔训练中正负样本构造不够充分。

### 2. 负样本策略
RocketQA 初版在负样本方面的关键改进包括：

1. **跨批次负样本**  
   不局限于单个 GPU 或单个 batch 内的负样本，而是使用跨批次队列或全局负样本，扩大负样本数量。这样可以在有限显存下获得更多 in-batch negatives。

2. **去噪难负样本**  
   对动态检索出的难负样本进行过滤，减少假阴性。具体做法可能包括用更强模型或人工/自动标注判断负样本是否真的不相关。  
   这里需要说明：RocketQA 初版中具体去噪机制，我记得包括对未标注数据中高分段落的处理，但不同版本细节可能有差异；如果你需要精确到公式或流程，建议核对原论文。

3. **数据增强与伪标签**  
   利用未标注问题或段落生成更多训练数据，并配合负样本采样。这样负样本不再只来自原始标注数据。

4. **更强的负样本采样组合**  
   结合 BM25 负样本、in-batch negatives、动态难负样本等，形成多来源负样本。

### 3. 与 ANCE 的区别
ANCE 强调“动态 ANN 难负样本”，但可能引入假阴性。  
RocketQA 则强调：

- 负样本要难；
- 但负样本也要尽量干净；
- 同时要通过跨批次、数据增强扩大负样本规模。

也就是说，RocketQA 把负样本策略从“单纯追求难”推进到“难而可信、规模大、可训练”。

### 4. 在主线中的位置
RocketQA 初版是承上启下：  
它继承 ANCE 的动态难负样本思想，但加入去噪、跨批次和数据增强，使负样本策略更系统、更工程化。

## 五、RocketQAv2：联合训练中的负样本、重排器与蒸馏协同

### 1. 背景
RocketQAv2 的核心不是单独训练检索器，而是 **联合训练双塔检索器和交叉编码器重排器**。它发现检索器和重排器可以互相促进：

- 重排器更强，可以为检索器提供更准确的监督；
- 检索器更好，可以为重排器提供更高质量的候选。

### 2. 负样本策略
在 RocketQAv2 中，负样本策略与联合训练、蒸馏紧密结合：

1. **动态难负样本**
